# Climate Change Dashboard | Power BI

Data analysis and interactive dashboard developed in Power BI for a postgraduate data visualization project. Explores global climate change trends and key environmental indicators.

## Objective
The goal of this project is to create interactive visualizations that help explore trends and patterns in global climate and environmental data, focusing on effective and clear visual representation.

## Dataset
The dataset contains over 1,200 records and 20 features covering global temperature, CO₂ levels, rainfall, sea level rise, extreme weather events, forest coverage, energy consumption, air quality, and climate risk.  
Source: (https://www.kaggle.com/datasets/algozee/climate-cahnge/data)

## Tools
- Power BI

## Key Visualizations
- Interactive charts showing temperature and CO₂ trends over time  
- Visual comparisons of multiple environmental indicators  
- Dashboard highlighting patterns, trends, and anomalies in climate data

## Conclusion
This project helped improve skills in data visualization, dashboard design, and understanding of global climate trends. It demonstrates the ability to create clear, interactive dashboards to communicate insights from multi-feature datasets.
